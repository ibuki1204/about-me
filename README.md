## 趣味

- こだわりポイントは写真を貼りつけたこと。その写真を押すと、拡大するようにしたこと。また文字を押すと、その文字についての詳細が表示されるようにしたことです。

## 宇治について

- こだわりポイントは写真の大きさを統一した。写真の角が丸みを帯びるようにした。

# 一番見てほしいところ

- 個人的に左上の三本線のメニューバーが一番上手くできたので見てほしいです。

# 力を入れた点

- 三本線のメニューバーがいかに綺麗に表示されるか何回も試行錯誤した。

## 実装面

- htmlは割ときれいにコードを整理できたので、とても見やすい。
- こだわったポイントは後から見ても分かるようにほんの少しだけですが、コードにメモを残した。 
- 教科書で授業してた時からcssに若干苦手意識があり、実際課題に取り組んだ際にもcssの書き方が分からず、コードがとても長くなったり、全然整理されていない状態になってしまった。

## デザイン面

- 私はシンプルで色も落ち着いた色が好きなので、webサイトもシンプルで落ち着いたものにしました。デザインの構成はchatgptにほとんど考えてもらったが、色は自分で考えました。
- 基本的に色は三色以内にしようと思い、読者の目が疲れないような色合いを意識してみました。
- 趣味のページの文字を押すと、その文字の詳細が出てくるところが一番難しかった。理想はそれぞれ独立させて詳細が出てくることなのですが、実際は大河ドラマは独立していたが、ゲームと外食の文字を押すと、二つ同時に詳細が出てこようとする。
